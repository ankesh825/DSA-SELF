## How to Run the Programs

**Step 1:** Clone the repository.

```bash
git clone https://github.com/ankesh825/DSA-SELF.git
```

**Step 2:** Open the project folder.

```bash
cd DSA-SELF
```

**Step 3:** Compile a C++ program using a C++ compiler.

```bash
g++ program.cpp -o program
```

**Step 4:** Run the compiled program.

```bash
./program
```

For C programs:

```bash
gcc program.c -o program
./program
```

Replace `program.cpp` or `program.c` with the actual filename. On Windows, the executable can be run using `.\program.exe`.
